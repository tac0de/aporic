# Context-selection pilot rubric

Freeze before participant agents start. Both arms receive identical Rust
source, public tests, and `TASK.md` from the same starting commit. The
baseline searches six dated repository notes. The treatment retrieves the
same six records from isolated Aporic memory; two older settlement rules are
linked as superseded, and one UI note is irrelevant.

## Primary outcome

The evaluator's hidden suite has seven checks for highest-revision selection,
duplicate-highest handling, void replacement, checked overflow, sorted nonzero
totals, merchant-scoped invoice identity, and empty input. The public smoke
test adds one point. A final note identifying all three current record IDs
(`SET-003`, `SET-004`, `SET-005`) adds one provenance point. Full score is 9/9.

Report the code-test subtotal separately from provenance. Also record stale
rule application, retrieval path, clarification requests, UTC elapsed time,
and per-run tokens only if actually available. The hidden tests and answer
key remain outside both workspaces until all agent work is complete.

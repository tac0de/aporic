# Product delivery examples

`web_game/manifest.json` and `web_platform/manifest.json` are repository-owned, declarative delivery packages. They demonstrate complete profile mappings and dependency graphs while retaining explicit unbound execution gaps.

Use the repository root as the workspace. Paths and SHA-256 digests refer to these checked-in fixture files. Their commands, supported browser targets and assertion descriptions are declarations. No browser observation, product pilot or runner receipt is represented as having occurred.

The source models are intentionally partial. These packages are examples of how to capture work and identify what remains; they are not complete web products.

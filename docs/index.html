03 / v0.3.1

Useful governance primitives, kept deliberately narrow.

REPLAY

Deterministic state

Event schema v2 replays in sequence with strict revision and state checks, plus explicit non-destructive migration from v1.

GLOBAL

Install once, bind explicitly

One global plugin discovers only projects with a local Aporic binding and isolates their state by canonical workspace path.

POLICY

Exact-action router

One deterministic evaluator drives startup context, explanation, and preventive checks for exact tool names in a strict JSON policy.

GRANT

Bounded execution

A grant binds plan, scope, session, tool, exact JSON input, and use limit; admission consumes one use before the tool runs.

Evaluation release

Aporic v0.3.1 is for dogfooding and evaluation, not a broad security boundary.

  • Rust 1.89 or newer to build the plugin package
  • macOS arm64 for the packaged Codex plugin
  • MIT or Apache-2.0, at your option
Open the repository ↗

What it does
not promise.

  • Not all agent actions. The packaged default protects apply_patch; other exact tool names require policy and host validation.
  • Not authenticated identity. Actor provenance is caller-declared, not cryptographically proven.
  • Not an atomic sandbox. A preventive decision is not atomically bound to the later filesystem effect.
  • Not tamper-proof storage. Cooperative locks and local records do not resist a hostile same-user process.

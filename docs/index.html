03 / v0.1.0

Useful governance primitives, kept deliberately narrow.

REPLAY

Deterministic state

Append-only JSONL events replay in sequence with strict schema, revision, and state-application checks.

CONTEXT

Bounded projection

Codex receives an explicit execution-state projection capped at 6,000 UTF-8 bytes—not a general token optimizer.

GATE

Preventive check

The first plugin gates apply_patch for one configured workspace and scope, failing closed when required state is unavailable.

LOCAL

Inspectable record

The local event log makes plans, authorizations, holds, decisions, risks, and open Aporia inspectable.

What it does
not promise.

  • Not all agent actions. The initial package protects only its configured apply_patch path.
  • Not authenticated identity. Actor provenance is caller-declared, not cryptographically proven.
  • Not an atomic sandbox. A preventive decision is not atomically bound to the later filesystem effect.
  • Not tamper-proof storage. Cooperative locks and local records do not resist a hostile same-user process.

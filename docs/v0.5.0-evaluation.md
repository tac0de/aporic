# Aporic 0.5.0 evaluation

## Acceptance surface

- Event schema v3 replays evidence, claims, plan bases, action outcomes, verifications, completion, and checkpoints deterministically.
- An `observed` claim cannot rely only on `agent_inference`; verified and refuted transitions require evidence in the same scope.
- Plan completion is rejected until each acceptance check's latest verification passes, unless the event names accepted residual risks.
- `PostToolUse` retries are idempotent and record `unknown`, never inferred success.
- `SessionEnd` publishes a checkpoint from recorded state; the next distinct session can claim one checkpoint once.
- v1 and v2 migration copy into schema v3 without mutating the source.

## Verification

Run:

```console
cargo fmt --check
cargo test --locked
cargo clippy --all-targets --locked -- -D warnings
jq empty schemas/*.json packaging/codex-plugin/hooks/hooks.json packaging/codex-plugin/.codex-plugin/plugin.json
```

Focused regression coverage lives in `tests/v050.rs`. The release remains experimental: actor identity, provenance, and evidence locators are caller-declared; checkpoints do not inspect transcripts; and tool-specific `PostToolUse` responses are not interpreted as success attestations.

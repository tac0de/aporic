# Aporic 0.6.0 evaluation

## Acceptance surface

- Event schema v4 replays typed argument relations, belief revisions, decision bases, and decision reviews deterministically.
- New relations require two distinct active claims in the same scope and reject identical active duplicates.
- Belief revisions reject stale prior status and require non-inference evidence before verification or refutation.
- Decision reviews require a recorded decision basis and direct evidence, preserve lessons and follow-up claims, and reject basis references recorded after the decision.
- Schema v3 migration copies to v4 without mutating the source.
- `analyze-wasm` rejects imports, excessive table elements, fuel exhaustion, excessive configured fuel or memory, oversized artifacts, out-of-bounds or malformed output, and stale output revisions without mutating the store.
- The included structural analyzer reports only explicit graph conflicts and invalidated dependencies.

## Verification

Run:

```console
cargo fmt --check
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
jq empty schemas/*.json packaging/codex-plugin/hooks/hooks.json packaging/codex-plugin/.codex-plugin/plugin.json
```

Focused regression coverage lives in `tests/v060.rs`. A host-native build tests the analyzer algorithm and WAT modules exercise the Wasmtime ABI and failure paths. Building the included analyzer for `wasm32-unknown-unknown` additionally requires that Rust target; target installation and generated `.wasm` artifacts remain operator actions.

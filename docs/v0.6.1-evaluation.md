# Aporic 0.6.1 evaluation

## Acceptance surface

- `rust-toolchain.toml` pins Rust 1.89.0, `rustfmt`, Clippy, and `wasm32-unknown-unknown`.
- The structural analyzer builds as optimized Wasm and executes through the same bounded, import-free host used for other analyzer modules.
- Fresh macOS arm64 Codex plugin packages contain the host binary and `analyzers/structural.wasm`; `analyze-structural` resolves that package-relative module.
- Schema-v3 migration remains explicit and non-destructive; the original store is retained for rollback.
- The v0.6.0 argument graph, belief revision, decision retrospective, projection-v5, and analyzer-ABI-v1 acceptance surface remains unchanged.

## Verification

Run:

```console
rustc --version
rustup target list --installed
cargo fmt --all --check
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo build -p aporic-structural-analyzer --target wasm32-unknown-unknown --release --locked
jq empty schemas/*.json packaging/codex-plugin/hooks/hooks.json packaging/codex-plugin/.codex-plugin/plugin.json
```

Release verification additionally builds a fresh plugin package, validates it, migrates a copy of the bound schema-v3 store, and executes the packaged analyzer against that migrated store. Generated package artifacts and live stores are host state rather than committed source files.
